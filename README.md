# captur-seedance-ref

Seedance 2.5 に参考動画として渡すための置き場所です（API は参考動画をネット上のリンクでしか受け付けないため）。

- `v08_motion_720p.mp4`：captuR PartyBox の動きとカメラの見本（Blender の簡易3D、5秒、720×1280、24fps）。1回目に使用
- `PartyBox_v10_motion_720p.mp4`：v10 の動きとカメラの見本（女の子は箱の正面、風船は右へ流れる。5秒、720×1280、24fps）。2回目の @Video 1
- `PartyBox_v10_ribbon_reference.mp4`：v10 のリボンだけの寄りの見本（2.5秒、1280×720、24fps）。2回目の @Video 2
- `test1_intro_0-3s.mp4`：test 1（以前 Seedance で作った見本の動画）の最初の3秒、音なし（720×1280、24fps）。4回目の @Video 3。構成と風船だけの見本
- `test1_audio.mp3`：test 1 の音（約10秒）。4回目の @Audio 1。音楽の見本
- `PartyBox_v11_motion_720p.mp4`：v11 の 0〜10秒全部の見本（導入・リボンと箱が開く動き・Hero Shot の配置。10秒、720×1280、24fps）。5回目の @Video 1
- `PartyBox_v11_ribbon_reference.mp4`：v11 のリボンだけの寄りの見本（広告の 3.3〜5.8秒、1280×720、24fps）。5回目の @Video 2
- `PartyBox_v13_girl_720p.mp4`：v13 の女の子の場面（0〜6.5秒）。粗い無地の3D（水色の人形、灰色の机、ターコイズの箱、白い風船）。720×1280、24fps。6回目の @Video 1
- `PartyBox_v13_ribbon_reference.mp4`：v13 のリボンだけの寄り（2.5秒、1280×720）。6回目の @Video 2
- `PartyBox_v13_hero_720p.mp4`：v13 の Hero Shot（3.5秒、色分けした粗い小物）。720×1280。6回目の @Video 3
