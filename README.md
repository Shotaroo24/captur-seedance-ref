# captur-seedance-ref

Seedance 2.5 に参考動画として渡すための置き場所です（API は参考動画をネット上のリンクでしか受け付けないため）。

- `v08_motion_720p.mp4`：captuR PartyBox の動きとカメラの見本（Blender の簡易3D、5秒、720×1280、24fps）。1回目に使用
- `PartyBox_v10_motion_720p.mp4`：v10 の動きとカメラの見本（女の子は箱の正面、風船は右へ流れる。5秒、720×1280、24fps）。2回目の @Video 1
- `PartyBox_v10_ribbon_reference.mp4`：v10 のリボンだけの寄りの見本（2.5秒、1280×720、24fps）。2回目の @Video 2
- `test1_intro_0-3s.mp4`：test 1（以前 Seedance で作った見本の動画）の最初の3秒、音なし（720×1280、24fps）。4回目の @Video 3。構成と風船だけの見本
- `test1_audio.mp3`：test 1 の音（約10秒）。4回目の @Audio 1。音楽の見本
